How it works

The contract believes only answers to its own OutLayer requests, for the exact engine build it pinned. The agent can request decisions and settle what the engine authorized, nothing else.

Verify it yourself

Independently verify an OutLayer engine execution’s Intel TDX attestation (6 checks, Intel root of trust):

git clone https://github.com/growthmindsetgg/takara-ai.git
cd takara-ai && npm install
node scripts/verify-attestation.mjs 30883 \
  dc3e7c5c406cea1872b338cfed59bb14ed37a422f5bb31486d02346f94a7f019 \
  '{"request":"step0-onchain","treasury":"takara-ai-hq.testnet"}' \
  '{"ok":true,"engine":"takara-ai-engine","step":0,"input_len":61,"echo":"request:step0-onchaintreasury:takara-ai-hq.testnet"}'

Run all ten checks on your own deployment:

TAKARA_OWNER=<you>.testnet node scripts/setup-testnet.mjs
node scripts/judge.mjs
node backend/server.mjs   # local owner dashboard
