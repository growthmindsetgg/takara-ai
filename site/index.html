Live on NEAR testnet

Never spend tomorrow’s payroll on today’s expenses.

Takara AI is a non-custodial treasury for small businesses on NEAR. The business owns the treasury contract and its funds. An AI agent pays bills only inside a policy the owner signs, and the owner can revoke it at any time without the agent’s cooperation.

Open the live app View on GitHub Judge checks
  • 10 of 10 judge checks pass as real transactions against the live testnet treasury.
  • The owner recovers funds with the agent offline. The agent’s own withdrawal is refused with E_NOT_OWNER. See check 8
  • Decisions come from a pinned engine build. The contract accepts answers only from the TEE policy engine whose wasm hash it pinned.

Judge checks

Every check is real transactions against the live treasury, and each step links to the explorer. Re-run with node scripts/judge.mjs.

How it works

The contract believes only answers to its own OutLayer requests, for the exact engine build it pinned. The agent can request decisions and settle what the engine authorized, nothing else.

Verify it yourself

Reproduce the proof from your own machine instead of trusting this page.

Check an engine attestation

Independently verify an OutLayer engine execution’s Intel TDX attestation (6 checks, Intel root of trust):

git clone https://github.com/growthmindsetgg/takara-ai.git
cd takara-ai && npm install
node scripts/verify-attestation.mjs 30883 \
  dc3e7c5c406cea1872b338cfed59bb14ed37a422f5bb31486d02346f94a7f019 \
  '{"request":"step0-onchain","treasury":"takara-ai-hq.testnet"}' \
  '{"ok":true,"engine":"takara-ai-engine","step":0,"input_len":61,"echo":"request:step0-onchaintreasury:takara-ai-hq.testnet"}'

Run all ten checks on your own deployment

Deploy a fresh treasury you own, then run the judge suite and the local owner dashboard:

TAKARA_OWNER=<you>.testnet node scripts/setup-testnet.mjs
node scripts/judge.mjs
node backend/server.mjs   # local owner dashboard

The confidential payout via NEAR Intents 1Click is a separately labelled mainnet integration demo. The testnet contract does not enforce it.
